WHAT I BUILT

The specialist agents (productivity, calendar and email, research, memory), each carrying only its own tools and rules. The Google Workspace tool layer: Gmail, Calendar, Drive and Docs actions on the user's real accounts through Composio OAuth. The sharing system for lists, notes and groceries between accounts. The real-time voice path on OpenAI Realtime and Gemini Live, sharing tools and memory with text.

HOW IT DECIDES

Six decisions before the model is called: grade the request, pick fast, strong or top-tier model by mode, hand over 3 to 6 of 31 tools by keyword match, load a domain playbook, fetch memory only when needed, and forbid answering about user data without a real tool call.

WHY IT MATTERS

Cost spread of roughly 20 to 1 between modes sits under one toggle. Proactive briefings run on a schedule, so the product works when nobody is looking at it. Structurally blocked from claiming an action it did not perform.

02 · GOVERNED AI FOR ARCHITECTURE PRACTICES

ArchLab

An assistant layer over Microsoft 365 that files correspondence, turns meetings into minutes and drafts replies in the sender's own voice. It never sends and never files on its own.

Next.jsPrisma · PostgreSQLMicrosoft GraphDeepgramOpenRouter

WHAT I BUILT

Most of the backend. The organisation-level Microsoft 365 connection: application-level Graph access for shared project mailboxes and SharePoint filing, kept separate from per-user delegated access, tokens encrypted at rest, send-mail permission never requested. Teams transcript retrieval and the Deepgram speaker-separated path feeding the minutes workflow.

RULES FIRST, MODEL SECOND

Email is matched to projects by explicit scores: verified sender 1.00, domain 0.99, aliases and keywords as small increments. Only 0.90 and above may auto-file; below that it waits for a person. The model is asked only where rules cannot resolve, under a strict JSON contract, temperature 0.2, repaired once then failing loudly.

GUARDRAILS IN CODE

Nine-step minutes flow with an export gate: no PDF until minutes and the Word file are approved. Per-tenant prompts with a fixed safety clause admins cannot override. Usage ledger on every call, monthly cap enforced, audit trail that records actions but never content.
